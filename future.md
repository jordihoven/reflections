# Future Ideas

Things intentionally deferred from v1 to keep it lightweight. All confirmed as desirable — just not yet.

## UX improvements

- **Edit reflections** — edit text and attachments after posting
- **Hold-to-delete** — intentional gesture replaces confirmation dialog
- **Inline delete confirm** — delete button turns red with "Confirm" text, no modal
- **Attachment captions** — optional user-visible caption per attachment
- **Alt-text on images** — accessibility-friendly optional field per attachment
- **Backdating** — let user set a past date ("I remember this from last week")

## Social

- Interact with others' reflections (comments, likes, emoji responses)
- Other ATProto clients consuming Reflections Lexicon

## Product
