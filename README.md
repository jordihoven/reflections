# reflections

an iteration of [daily-reflections](https://github.com/jordihoven/daily-reflections), built on [atproto](https://atproto.com).

writing thoughts that are public by default, but feel private.

## Stack

- nextjs
- tailwindcss
- atproto
- opencode zen agent
- lucide icons

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm start` — run production build
- `npm run lint` — eslint
