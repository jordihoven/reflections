# Design Tokens

## Colors

| Token | Value | Usage |
|-------|-------|-------|
| primary | #0070F3 | Actions, links, active states |
| darkgrey | #444444 | Primary text |
| lightgrey | #888888 | Secondary text, placeholders |
| background | #fafafa | Page background |
| border | #e4e4e4 | Dividers, input borders |
